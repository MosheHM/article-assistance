# Quick Start Guide - Linguistic Lens

## 5-Minute Setup

### Step 1: Generate Icons (2 minutes)

1. Open `icons/GENERATE_ICONS.html` in your browser
2. Icons will be automatically generated
3. Click the three download buttons:
   - Download 128x128
   - Download 48x48
   - Download 16x16
4. Move the downloaded PNG files to the `icons/` folder

**Alternative**: Use any 128x128 PNG image as `icon128.png`, then resize it for the other sizes.

### Step 2: Get Gemini API Key (1 minute)

1. Visit: https://makersuite.google.com/app/apikey
2. Sign in with Google
3. Click "Create API Key"
4. Copy the key (starts with `AIza...`)

### Step 3: Load Extension (1 minute)

1. Open Chrome
2. Navigate to: `chrome://extensions/`
3. Enable "Developer mode" (toggle in top-right)
4. Click "Load unpacked"
5. Select the `linguistic-chrome-extension` folder

### Step 4: Configure (30 seconds)

1. Click the extension icon in Chrome toolbar
2. Paste your API key in the input field
3. Click "שמור" (Save)

### Step 5: Test (30 seconds)

1. Navigate to any English article (try Wikipedia or Medium)
2. Click the extension icon
3. Click "מצב מהיר" (Quick Mode)
4. Wait for analysis
5. Hover over color-coded words!

## That's it! 🎉

You're now ready to read English articles with real-time linguistic analysis.

## Tips

- **First use?** Start with shorter articles (500-1000 words)
- **Slow analysis?** Try Quick Mode instead of Deep Mode
- **Want to learn?** Mark words as learned by clicking "למדתי מילה זו"
- **Use frequently?** Pin the extension icon to your toolbar

## Troubleshooting

### Extension doesn't load?
- Make sure all files are in the correct folders
- Check that icons are present in `icons/` folder
- Reload the extension in `chrome://extensions/`

### Analysis fails?
- Verify your API key is correct
- Check your internet connection
- Make sure the page has English text

### Need help?
- Read the full README.md
- Check the console for error messages (F12)
- Open an issue on GitHub
